# お店のページを自分で書き換える（試し用）

書き換えるのは `editable/content.yml` の1つだけです。
ページ: https://rakuwork-kobo.github.io/samples/editable/

## 営業時間やお知らせを変える（github.com で）

1. github.com でこのリポジトリを開き、`editable` → `content.yml` を開きます。
2. 右上のえんぴつの印（Edit this file）を押します。
3. 変えたいところを書き換えます。
   - 「`: `」の右側だけを変えます。左側（`shop_name:` など）と、行の頭の空白はそのままにします。
   - お知らせを足すときは、`notices:` のすぐ下に2行まとめて足します（新しいものを上に）。
     ```
       - date: "2026-11-01"
         text: "ここにお知らせを書きます。"
     ```
4. 右上の緑の「Commit changes...」を押し、出てきた画面でもう一度「Commit changes」を押します。
5. 1〜2分待って、ページを開き直します（新しくならないときは、もう1分待って開き直します）。

## うまくいかなかったとき

- 上の「Actions」を開きます。いちばん上の行に赤い × が付いていたら、書き換えに失敗しています。
- そのときも、ページは前のまま出ています。壊れたページが出ることはありません。
- 赤い × の行を押し、「build」→「ページを作る」を開くと、どこが違うかが日本語で出ています。直してもう一度 Commit すれば大丈夫です。

## 入力欄（フォーム）で書き換えてみる（Pages CMS）

1. https://pagescms.org を開き、「Sign in with GitHub」で入ります。
2. 初めてのときは、このリポジトリへの許可を求められるので、このリポジトリだけを選んで許可します。
3. 一覧からこのリポジトリを選び、「お店のページ（書き換えの試し用）」を開きます。
4. 店名・営業時間・定休日・お知らせ・メニュー・写真を入力欄で直し、「Save」を押します。
5. あとは上と同じく、1〜2分待ってページを開き直します。

- 写真を新しく入れるときは、ファイル名を英数字にしてください（例: `yakitori2.jpg`）。
- Pages CMS で保存すると、content.yml の中の説明書き（# の行）は消えることがあります。中身には差し支えありません。
